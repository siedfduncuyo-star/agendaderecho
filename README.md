# Agenda de Actividades · v29

Versión preparada para publicar en GitHub Pages.

## Cambios principales de v29

- Filtro compacto junto al contador: **Todo, Presenciales, Híbridas, Virtuales y Fechas destacadas**.
- Las **Fechas destacadas** incluyen Inscripciones, Mesas de examen, Recesos, Suspensión de actividades y otras fechas relevantes.
- Los feriados no muestran actividades aunque haya registros cargados en esa fecha; quedan visualmente apagados.
- Los días sin actividades también se muestran atenuados en las vistas de calendario.
- Se elimina **Transmisión** como modalidad. Los registros históricos de transmisión se muestran como **Híbridos**.
- En Abogacía, el tramo **Optativas / otras** pasa a mostrarse como **Optativa**.
- El campo **Tipo de actividad** cambia según el área organizadora:
  - Secretaría de Posgrado: Doctorado, Maestría, Especialización, Diplomatura, Defensa de tesis, Seminario, Curso y Jornada/s.
  - Secretaría General: Consejo Directivo.
  - Secretaría Académica: Materia, Examen final, Curso, Capacitación, Taller, Jornada/s, Congreso y Servicio.
  - Investigación, Ciencia y Técnica; Relaciones Estudiantiles y Egresados/as; Extensión, Vinculación y Territorio: Curso, Capacitación, Taller, Jornada/s, Congreso y Servicio.
- Cada tarjeta ampliada tiene **Copiar para WhatsApp**. El texto se copia ordenado y con negritas compatibles con WhatsApp.
- En vista pública, la copia respeta la privacidad: nunca incluye un enlace privado ni datos exclusivos de administración.
- En vista administradora, la copia incluye la información privada que se visualiza allí: responsable, cuenta, grabación, requerimientos y, cuando corresponde, el enlace de la actividad.
- En actividades presenciales no se muestran plataforma ni enlace en la visualización.

## Publicación

Subí todo el contenido de esta carpeta a la raíz del repositorio de GitHub Pages, conservando las carpetas `assets` y `firebase`.

Si reemplazás una versión anterior, conviene hacer una recarga forzada del navegador (`Ctrl + F5`) después de publicar.
